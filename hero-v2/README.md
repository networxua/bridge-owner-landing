Локально з кореня репозиторія:

```bash
python3 -m http.server 4174
```

Відкрити http://127.0.0.1:4174/hero-v2/ . Перевірені вікна: 1440×900 і 390×844.

Головне джерело ритму для рев’ю: https://networxua.github.io/red2-demo/scroll-v2/

## Виміряний кегль

Знято в headless Chrome з увімкненими локальними шрифтами. `document.fonts.check` для Cormorant Garamond і Manrope — так.

| 1440×900 | Лід | 17px | 1.45 | 0 | 400 |
| 1440×900 | H2 наступного екрана | 72px | 0.96 | −0.03em | 500 |
| 390×844 | H1 | 64px | 58.24px (0.91) | −1.92px | 500 |

На 1440 заголовок — три рядки: «Не просто / оцінка. / План продажу.» Ширина третього рядка 567px, правий край на x=623. Аркуш на цій висоті починається правіше, приблизно з x=661. На 390 чотири рядки, кегль у межах 60–68. Горизонтального скролу немає: `scrollWidth` дорівнює ширині вікна.

## Manifest концептуального кадру

| | |
|---|---|
| Файл | `hero-v2/bridge-owner-plan-concept.jpg` |
| Ім’я | Точно `bridge-owner-plan-concept.jpg`, копія байт у байт із переданого кадру |
| Розмір | 1280×720, JPEG |
| Що це | Арт-спрямований редакційний натюрморт: темний стіл, аркуш із кресленням, ручка, лінійка, макет маси. Мова одного кадру, не фото конкретного об’єкта |
| Роль | Повноекранний якір героя. На 1440 кадр зміщено вправо (`object-position: 100% 50%`), щоб макет лишився в кадрі, а темне поле зліва тримало заголовок. На 390 — `36% 50%`: темний верхній лівий кут під текст, край аркуша справа |
| Чим не є | Не лот, не адреса, не звіт клієнта, не готовий «План продажу», не фото з `assets/01`–`07` і не екстер’єр `08`/`09` |

Кредити: кадр переданий для цього прототипу, не викачаний зі стоку і не знятий з об’єкта Bridge. Окремої ліцензії третьої сторони немає. Референсні скріни локу на сторінку не вставлені. На саме зображення текст не накладено.

Підпис лише внизу наступного екрана і в мобільному меню: «Концепт сторінки для Bridge · план продажу — майбутній документ аргентства».

## Прогалини

- Герой не затверджений як фінальний. Далі за цим екраном сайту немає: ні каталогу, ні кейсу, ні форми, ні CRM.
- «Безкоштовно» стоїть тут, бо так сказано на зустрічі 6 листопада 2026. На чинному Webflow цієї обіцянки немає, і прототип її не видає за текст чинного сайту.
- Немає гарантії продажу, строку, ціни, району, площі чи історії угоди.
- Інтер’єри 01–07 у герой не входять: це звичайні місцеві кадри, затемнення не робить їх luxury. Екстер’єри 08/09 як «реальні об’єкти» не використані.
- Макет будинку на столі — реквізит кадру, не будинок у роботі Bridge.
- Контакти лише підтверджені: +38 (063) 593 30 19 і Instagram `@bridge__realty`. Окремого Telegram у матеріалах немає.
- Netlify, білінг, корінь GitHub Pages і `main` цим кроком не чіпаються.

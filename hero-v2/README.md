## Як відкрити

Версія з файлів репозиторія бере шрифти з `assets/fonts/` і кадр `hero-v2/bridge-owner-plan-concept.jpg`. Її треба віддавати з кореня:

```bash
python3 -m http.server 4174
```

Відкрити http://127.0.0.1:4174/hero-v2/ .

Окремий файл `hero-v2/standalone.html` самодостатній: CSS, скрипт, JPEG і кириличні woff2 вшиті як base64. Його можна завантажити і відкрити подвійним кліком або через `file://` без сервера і без мережі. Зовнішніх шрифтів і картинок він не просить.

Головне джерело для рев’ю: https://networxua.github.io/red2-motion-test/scroll-v2/

Знято в headless Chrome з увімкненими локальними шрифтами. `document.fonts.check` для Cormorant Garamond і Manrope — так.

На 1440 заголовок — три рядки: «Не просто / оцінка. / План продажу.» Ширина третього рядка 567px, правий край на x=623. Аркуш на цій висоті починається правіше, приблизно з x=661. На 390 чотири рядки, кегль у межах 60–68. Горизонтального скролу немає: `scrollWidth` дорівнює ширині вікна.

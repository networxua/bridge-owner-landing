```bash
python3 -m http.server 4174
```

Відкрити http://127.0.0.1:4174/hero-v2/ .

## Виміряний кегль

Знято в headless Chrome з увімкненими локальними шрифтами. `document.fonts.check` для Cormorant Garamond і Manrope — так.

| Вікно | Елемент | Кегль | Інтерліньяж | Трекінг | Насичення |
|---|---|---|---|---|---|
| 1440×900 | H1 | 156px (`clamp(86px, 10.8333vw, 168px)`) | 141.96px (0.91) | −4.68px (−0.03em) | 500 |
| 1440×900 | Лід | 17px | 1.45 | 0 | 400 |
| 390×844 | H1 | 54px | 49.68px (0.92) | −1.62px | 500 |
| 390×844 | Лід | 15px | 1.45 | 0 | 400 |

На 1440 два рядки. «Не просто оцінка.» — 1066×141.96 px, лівий край x=56, правий x=1122. 1066/1440 = 74.03% ширини вікна. Правий край 1122/1440 = 77.92%. «План продажу.» — один рядок 884 px (61.39% вікна), `white-space: nowrap`. На 390 три рядки. «План продажу.» — 306 px, 306/390 = 78.46%, правий край x=324. Герой 844 px заввишки, горизонтального скролу немає.
